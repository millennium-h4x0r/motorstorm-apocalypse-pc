# Roadmap

Goal: the whole game playable natively, split-screen included, with the
finish of the inFAMOUS 2 port (port menu, options, up to 4K, a real 60+ fps
simulation). Design: [superpowers/specs/2026-11-03-motorstorm-recomp-design.md](superpowers/specs/2026-11-03-motorstorm-recomp-design.md).

| # | Milestone | Done when | State |
|---|---|---|---|
| 1 | Lift and link | a binary that starts and reaches the game's entry | ✅ 2026-11-03 |
| 2 | First pixels | boot logos / first intro video on screen | ✅ 2026-11-04 |
| 3 | Menus | the game's main menu navigated with a (virtual) pad | ✅ 2026-11-04 |
| 4 | First race | one race finished start to end | 🔧 |
| 5 | Full feature set | a Festival event and a 4-player split-screen race complete; every track loads | ⬜ |
| 6 | Polish | port menu, F1 options, resolution scale, fullscreen/letterbox, hang dumps, README screenshots | ⬜ |
| 7 | Performance | steady 60+ fps simulation at 1440p in single-player races | ⬜ |

Testing is automated (virtual pads, recorded input, frame checks): see the
design's "Working mode".
